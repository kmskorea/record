# Record — 하루 기록

하루를 기록하고, 쌓인 기록에서 내 패턴을 찾아보는 개인용 앱.
브라우저만 있으면 노트북에서도 휴대폰에서도 열리고, 홈 화면에 설치하면 앱처럼 쓸 수 있습니다.

## 화면 구성

하단 버튼 3개로 이동합니다.

### 흐름 (왼쪽)

- **달력** — 날짜마다 그날 컨디션에 따라 색이 칠해집니다. 파랑(좋음, 4~5) / 노랑(보통, 3) / 빨강(별로, 1~2), 컨디션은 안 적었지만 뭔가 기록한 날은 작은 점으로 표시됩니다. 날짜를 누르면 그날 기록을 전부 펼쳐 보고 바로 고칠 수 있습니다.
- **트래킹** — 수면시간, 컨디션, 운동량, 식사량, 몸무게, 단백질, 수분, 크레아틴, 당분, 할일 완수율을 시계열로 봅니다. 항목을 **여러 개 누르면 겹쳐서** 그려지고, 아래에 두 항목의 실제 상관계수가 함께 나옵니다. 기간은 7 / 30 / 90일.
- **인사이트** — 달력과 그래프만으로는 안 보이는 것들:
  - 연속 기록 일수, 평균 컨디션·수면, 운동한 날, 할일 완수율
  - 하루 점수 분포 (좋음/보통/별로 비율)
  - 요일별 평균 컨디션 — "금요일이 가장 좋고, 수요일이 가장 힘들었어요"
  - **발견** — 기록이 겹치는 항목쌍을 전부 훑어서 관계가 뚜렷한 것을 자동으로 찾아줍니다
  - 최근 자주 만난 사람

### 오늘 (가운데)

- **사전 관리** — 오늘 할 일(체크박스, 추가·삭제) / 수면(취침·기상 시각을 넣으면 잔 시간 자동 계산) / 컨디션 5단계와 그 이유
- **하루 중** — 아이디어. 떠오를 때마다 한 줄씩, 시각과 함께 쌓입니다
- **사후 관리** — 운동(여부, 부위 다중선택 + 직접 추가, 강도 3단계, 메모) / 몸무게 / 식습관(끼니별 양 5단계 + 단백질·수분·크레아틴·당분 각 5단계) / 관계(사람 등록, 관계는 자유 입력, 오늘 있었던 일) / 자기성찰 일기

### 검색 (오른쪽)

기록한 모든 글에서 단어를 찾습니다. 할일·아이디어·컨디션 이유·운동 메모·관계 기록·일기가 모두 대상이고, 검색어는 결과에서 하이라이트됩니다.
사람은 프로필로 따로 뜨고, 누르면 **그 사람에 대해 적은 모든 내용**을 한 번에 볼 수 있습니다.

### 알림

설정(오늘 탭 우측 상단 톱니)에서 켭니다. 기본값은 아침 9:30(할 일 정리), 밤 11:30(하루 마무리)이고 시각은 바꿀 수 있습니다.

> 브라우저 알림은 앱이 열려 있거나 백그라운드에 살아 있을 때 도착합니다. 홈 화면에 설치해두면 더 안정적입니다. 앱을 완전히 종료한 상태에서도 확실히 받으려면 푸시 서버가 필요합니다.

## 실행

```bash
npm install
npm run dev      # http://localhost:5173 (같은 와이파이면 휴대폰에서도 접속 가능)
npm run build    # dist/ 에 정적 파일 생성
npm run preview
```

## 두 기기에서 쓰기

정적 사이트라서 아무 정적 호스팅에나 올리면 됩니다.

- **GitHub Pages** — 저장소 Settings → Pages → Source를 **GitHub Actions**로 바꾸면 `main`에 푸시될 때마다 `.github/workflows/deploy.yml`이 자동 배포합니다.
- **Vercel / Netlify / Cloudflare Pages** — 빌드 명령 `npm run build`, 출력 폴더 `dist`.
- 하위 경로(`example.com/record/`)에 올릴 때는 `BASE_PATH=/record/ npm run build`.

배포한 주소를 휴대폰 사파리/크롬에서 열고 **홈 화면에 추가**하면 앱 아이콘으로 실행됩니다.

### 기록은 어디에 저장되나

기기의 브라우저(localStorage)에 저장됩니다. 서버로 아무것도 보내지 않는 대신, **노트북과 휴대폰의 기록은 각각 따로 쌓입니다.**
설정 → 데이터에서 JSON으로 내보내고 다른 기기에서 불러오면 옮길 수 있습니다. 기기가 바뀔 일에 대비해 가끔 내보내 두세요.

기기 간 자동 동기화가 필요해지면 `src/lib/storage.ts`(읽기/쓰기)와 `src/lib/store.tsx`(상태)만 원격 저장소로 바꾸면 나머지 화면은 그대로 씁니다.

## 수정 가이드

`npm run dev`로 띄워두면 저장하는 즉시 화면에 반영됩니다. 자주 건드리게 되는 곳:

| 바꾸고 싶은 것 | 파일 | 위치 |
|---|---|---|
| 달력 색 기준 (컨디션 말고 다른 기준으로) | `src/lib/metrics.ts` | `dayScore()` |
| 달력 색상값 (파랑/노랑/빨강) | `src/lib/metrics.ts` | `SCORE_COLOR` |
| 트래킹 항목 추가·삭제·이름·단위 | `src/lib/metrics.ts` | `METRICS` |
| 발견 카드 민감도 | `src/lib/metrics.ts` | `findDiscoveries()`의 `minPairs`, `0.35` |
| 운동 부위 기본 목록 | `src/lib/types.ts` | `WORKOUT_PARTS` |
| 끼니 종류 | `src/lib/types.ts` | `MEAL_LABELS` |
| 알림 기본 시각 | `src/lib/types.ts` | `DEFAULT_NOTIFICATIONS` |
| 알림 문구 | `src/lib/notifications.ts` | `SLOT_COPY` |
| 인사이트 집계 기간 (30일) | `src/features/calendar/InsightsPanel.tsx` | `WINDOW` |
| 그래프 기간 버튼 (7/30/90일) | `src/features/calendar/TrackingChart.tsx` | `RANGES` |
| 영양소 항목 (단백질·수분·크레아틴·당분) | `src/features/today/sections.tsx` | `DietSection`의 `nutrients` |
| 오늘 탭 섹션 순서 | `src/features/today/TodayScreen.tsx` | JSX 순서 그대로 |
| 전체 색·여백·폰트 | `src/styles/global.css` | 맨 위 `:root` 토큰 |

### 기록 항목을 새로 추가하려면

예를 들어 카페인을 넣는다면 순서대로:

1. `src/lib/types.ts` — 모델에 필드 추가 + `emptyDay()`에 기본값
2. `src/features/today/sections.tsx` — 입력 UI 추가
3. `src/lib/metrics.ts` — 그래프에도 띄우려면 `METRICS`에 항목 추가
4. `src/lib/search.ts` — 글자로 검색되게 하려면 `searchAll()`에 추가

### 고칠 때 기록이 날아가지 않게

코드를 고쳐도 기록은 남습니다. 브라우저 localStorage에 따로 저장되고, 배포해도 주소가 같으면 유지됩니다. 다만 세 가지를 주의하세요.

- **주소가 바뀌면 기록이 따라오지 않습니다.** 호스팅을 옮기면 새 주소는 빈 상태입니다. 옮기기 전에 설정 → 데이터 → 내보내기로 JSON을 받아 새 주소에서 불러오세요.
- **필드를 새로 추가하면 예전 날짜에는 그 값이 없습니다.** 저장된 기록은 그 시점 모양 그대로 읽히므로 새 필드는 옛 기록에서 `undefined`입니다. 읽을 때 `?? 기본값`을 붙이세요. 예전 기록을 한 번에 채우고 싶으면 `src/lib/storage.ts`의 `migrate()`에서 처리하면 됩니다.
- **브라우저 데이터를 지우면 사라집니다.** 가끔 내보내 두세요.

## 구조

```
src/
  lib/
    types.ts          데이터 모델 (하루 기록, 사람, 알림 설정)
    date.ts           'YYYY-MM-DD' 로컬 날짜 유틸, 달력 그리드
    storage.ts        localStorage 읽기/쓰기, 마이그레이션, 백업 JSON
    store.tsx         전역 상태 (React Context)
    metrics.ts        트래킹 지표 정의, 하루 점수, 상관계수, 인사이트 계산
    search.ts         전체 기록 검색, 인물 타임라인, 하이라이트
    notifications.ts  알림 권한과 예약 시각 감시
  components/         Card, Chip, ScaleInput, Sheet 등 공용 UI + 아이콘
  features/
    calendar/         달력, 트래킹 차트(SVG 직접 그림), 인사이트, 날짜 상세
    today/            오늘 입력 섹션들(날짜를 받아 과거 기록 수정에도 재사용), 설정
    search/           검색 화면, 인물 프로필
  styles/global.css   디자인 토큰과 컴포넌트 스타일 (라이트/다크)
```

차트는 라이브러리 없이 SVG로 직접 그립니다. 의존성은 React뿐입니다.
